====================================================================
                   ۵. عیب‌یابی (Troubleshooting)
====================================================================

🔴 ۵.۱ خطا: "port is already allocated"

┌─────────────────────────────────────────────────────────────────┐
│  راه‌حل:                                                      │
│  ─────────────────────────────────────────────────────────────  │
│  ۱. کانتینر قبلی را حذف کنید:                                 │
│     docker rm -f farmtech-postgres                            │
│  ۲. یا پورت را تغییر دهید:                                   │
│     در فایل docker-compose.yml پورت 5432:5432 را به           │
│     5433:5432 تغییر دهید                                     │
└─────────────────────────────────────────────────────────────────┘

🔴 ۵.۲ خطا: "TLS handshake timeout"

┌─────────────────────────────────────────────────────────────────┐
│  راه‌حل:                                                      │
│  ─────────────────────────────────────────────────────────────  │
│  ۱. تنظیم Mirror در daemon.json                               │
│  ۲. ری‌استارت Docker Desktop                                  │
│  ۳. استفاده از VPN یا Proxy                                   │
└─────────────────────────────────────────────────────────────────┘

🔴 ۵.۳ خطا: "WSL needs updating"

┌─────────────────────────────────────────────────────────────────┐
│  راه‌حل:                                                      │
│  ─────────────────────────────────────────────────────────────  │
│  ۱. wsl --update                                              │
│  ۲. wsl --set-default-version 2                               │
│  ۳. ری‌استارت سیستم                                           │
└─────────────────────────────────────────────────────────────────┘

🔴 ۵.۴ خطا: "permission denied" یا "access denied"

┌─────────────────────────────────────────────────────────────────┐
│  راه‌حل:                                                      │
│  ─────────────────────────────────────────────────────────────  │
│  ۱. اضافه شدن به گروه docker-users:                           │
│     net localgroup docker-users "%USERNAME%" /add             │
│  ۲. خروج و ورود مجدد به ویندوز                               │
│  ۳. اجرای VS Code و PowerShell به عنوان Administrator         │
└─────────────────────────────────────────────────────────────────┘

====================================================================
                   ۷. مراحل سریع برای شروع کار
====================================================================

🚀 ۷.۱ اگر کانتینرها متوقف هستند:

   docker-compose up -d

🚀 ۷.۲ اگر می‌خواهید از ابتدا شروع کنید:

   docker-compose down -v
   docker-compose up -d

🚀 ۷.۳ بررسی وضعیت کانتینرها:

   docker ps

🚀 ۷.۴ اتصال به دیتابیس از VS Code:

   Host: localhost
   Port: 5432
   Username: postgres
   Password: mysecretpassword
   Database: farmtech_db
